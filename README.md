# AI Learning Sensei

Персональный практический наставник для системного изучения **искусственного интеллекта**. Работает как проектный навык в Codex и Claude Code, начинает с интервью, собирает темы только из источников пользователя, ведёт единый бэклог и сохраняет ретроспективы занятий.

## Что внутри

- первичное интервью о целях, уровне, рабочих задачах и ритме занятий;
- пользовательские RSS/Atom-ленты, веб-страницы, GitHub-репозитории, локальные файлы и ручные идеи;
- фильтр «только ИИ»: новости без практического эксперимента и нерелевантные материалы не попадают в рекомендации;
- один актуальный `BACKLOG.md` вместо копий таблицы в чатах;
- практические занятия до заданной длительности, каждое в отдельной задаче или вкладке;
- SQLite-память о выборе тем, результатах, сложности и полезности;
- русскоязычный и англоязычный интерфейс наставника.

## Быстрый старт

Нужны Git и Python 3.10+; внешние Python-пакеты не требуются. Если Windows не распознаёт выбранную IANA-таймзону, скрипт использует локальную таймзону системы; необязательно можно установить пакет `tzdata`.

```bash
git clone https://github.com/sntrainer-lab/ai-learning-sensei.git
cd ai-learning-sensei
```

Откройте папку в Codex или запустите в ней Claude Code, затем напишите:

```text
Настрой мне ИИ-сенсея и проведи стартовое интервью.
```

Наставник задаст вопросы одним компактным блоком, согласует ритм обучения, создаст локальные `config/profile.json` и `config/sources.json`, и подготовит первый бэклог. После настройки можно писать:

```text
Начать занятие
```

Каждое занятие должно идти в новой задаче/вкладке. Если среда умеет создавать задачи, наставник сделает это сам. Иначе он даст короткий стартовый промпт для новой вкладки.

## Источники пользователя

Поддерживаются:

- `rss` — RSS или Atom;
- `web` — конкретная публичная веб-страница;
- `github` — публичный GitHub-репозиторий;
- `file` — локальный текстовый или Markdown-файл;
- `manual` — ссылка, файл, название инструмента или идея, переданная в диалоге.

Источники задаются во время интервью и позднее редактируются в `config/sources.json`. Пример структуры находится в `config/sources.example.json`.

Сбор и обновление бэклога:

```bash
python .agents/skills/ai-learning-sensei/scripts/collect_sources.py
python .agents/skills/ai-learning-sensei/scripts/sensei_store.py maintain
```

Добавить идею вручную:

```bash
python .agents/skills/ai-learning-sensei/scripts/sensei_store.py ingest --source manual --title "AI-агент для анализа заявок" --text "Собрать проверяемый прототип на реальных данных"
```

## Приватность

По умолчанию Git не отслеживает пользовательские конфиги, `BACKLOG.md`, базу `data/sensei.db` и ретроспективы. Не добавляйте в источники токены, закрытые сообщения, приватные ссылки или файлы с персональными данными. Сборщик только читает источники и не публикует, не комментирует и не изменяет внешние аккаунты.

## Устройство репозитория

```text
.agents/skills/ai-learning-sensei/   навык для Codex (каноническая копия)
.claude/skills/ai-learning-sensei/   тот же навык для Claude Code
config/*.example.json                шаблоны интервью и источников
data/                                локальная SQLite-память
retrospectives/                      локальная история занятий
AGENT_GUIDE.md                       общие правила наставника
AGENTS.md                            вход для Codex
CLAUDE.md                            вход для Claude Code
```

После изменения канонического навыка синхронизируйте Claude-копию и запустите проверки:

```bash
python scripts/sync_skills.py
python -m unittest discover -s tests -v
```
