# AI Learning Sensei

<p align="center">
  <img src="assets/ai-learning-sensei.png" alt="AI Learning Sensei" width="160">
</p>

Это готовый личный наставник для изучения искусственного интеллекта. Он помогает не теряться в потоке новых инструментов, превращает интересные материалы в понятный план и проводит короткие практические занятия.

Вы рассказываете, зачем вам ИИ, чему хотите научиться и откуда обычно берёте информацию. Сенсей сам поддерживает порядок: выбирает полезные темы, предлагает следующий шаг, запоминает прогресс и не повторяет уже освоенное без причины.

## Чем он полезен

- помогает выбрать, что изучать сейчас, а что можно отложить;
- оставляет только темы, связанные с ИИ и реальными задачами пользователя;
- превращает материалы в практику с конкретным результатом;
- ведёт один актуальный список тем и историю пройденных занятий;
- проверяет понимание через объяснение своими словами, исправление или перенос в новую задачу;
- собирает проверенные выводы разных занятий в одну личную базу знаний;
- подстраивает сложность и следующие рекомендации по обратной связи;
- проводит каждое занятие в отдельной задаче или вкладке, чтобы история не смешивалась.

## Как это работает

1. При первом запуске сенсей проводит короткое интервью: спрашивает о целях, опыте, рабочих задачах и удобном ритме обучения.
2. Пользователь выбирает открытые источники, за которыми хочет следить.
3. Сенсей собирает подходящие AI-темы, убирает повторы, рекламу и новости без практической пользы.
4. Перед занятием он показывает три сильные темы. Пользователь выбирает одну или предлагает свою.
5. Занятие идёт небольшими шагами и по возможности заканчивается рабочим артефактом: промптом, схемой, автоматизацией, прототипом или документом.
6. Перед завершением сенсей проверяет, что пользователь может объяснить или перенести изученное, а не только повторить инструкцию.
7. После занятия сенсей сохраняет результат, оценки пользы и сложности, обновляет план и пополняет `KNOWLEDGE.md` проверенными знаниями и темами для закрепления.

## Откуда сенсей берёт темы

Источники всегда выбирает сам пользователь. Это могут быть:

- сайты, статьи, рассылки и RSS-ленты;
- GitHub-репозитории;
- локальные заметки и файлы;
- ссылки и идеи, отправленные сенсею вручную;
- Telegram-каналы по выбору пользователя;
- выбранные страницы в социальных сетях.

По умолчанию речь идёт о чужих публичных каналах и страницах, которые можно открыть без входа в аккаунт. Пользователь сам выбирает их, а сенсей только читает доступные всем публикации и отбирает материалы про ИИ. Он не входит в соцсети от имени пользователя, не подписывается, не ставит реакции и ничего не публикует.

При желании можно добавить собственную выгрузку или уже настроенный в Codex/Claude Code коннектор. Такой доступ должен быть явно разрешён владельцем аккаунта. Пароли, cookies и токены нельзя помещать в репозиторий или отправлять сенсею в чате.

## Быстрый старт

```bash
git clone https://github.com/sntrainer-lab/ai-learning-sensei.git
cd ai-learning-sensei
```

Откройте папку в Codex или запустите в ней Claude Code, затем напишите:

```text
Настрой мне ИИ-сенсея и проведи стартовое интервью.
```

Наставник задаст вопросы одним компактным блоком, согласует ритм обучения, создаст локальные `config/profile.json` и `config/sources.json`, и подготовит первый бэклог. После настройки можно писать:

```text
Начать занятие
```

Каждое занятие должно идти в новой задаче/вкладке. Если среда умеет создавать задачи, наставник сделает это сам. Иначе он даст короткий стартовый промпт для новой вкладки.

## Технические требования и настройка

Нужны Git и Python 3.10+. Внешние Python-пакеты не требуются. Если Windows не распознаёт выбранную таймзону, используется локальная таймзона системы; при желании можно установить пакет `tzdata`.

В файле `config/sources.json` используются следующие технические типы источников:

- `rss` — RSS или Atom;
- `web` — конкретная публичная веб-страница;
- `github` — публичный GitHub-репозиторий;
- `file` — локальный текстовый или Markdown-файл;
- `telegram` — выбранный публичный Telegram-канал, доступный без входа;
- `social` — выбранная публичная страница социальной сети, доступная без входа;
- `manual` — ссылка, файл, название инструмента или идея, переданная в диалоге.

Источники задаются во время интервью и позднее редактируются в `config/sources.json`. Пример структуры находится в `config/sources.example.json`.

Сбор и обновление бэклога:

```bash
python .agents/skills/ai-learning-sensei/scripts/collect_sources.py
python .agents/skills/ai-learning-sensei/scripts/sensei_store.py maintain
```

Добавить идею вручную:

```bash
python .agents/skills/ai-learning-sensei/scripts/sensei_store.py ingest --source manual --title "AI-агент для анализа заявок" --text "Собрать проверяемый прототип на реальных данных"
```

## Приватность

По умолчанию Git не отслеживает пользовательские конфиги, `BACKLOG.md`, базу `data/sensei.db` и ретроспективы. Не добавляйте в источники токены, закрытые сообщения, приватные ссылки или файлы с персональными данными. Сборщик только читает источники и не публикует, не комментирует и не изменяет внешние аккаунты.

## Устройство репозитория

```text
.agents/skills/ai-learning-sensei/   навык для Codex (каноническая копия)
.agents/skills/ai-learning-session/  активное обучение, практика и проверка понимания
.agents/skills/ai-knowledge-synthesis/ накопительная суммаризация и повторение
.claude/skills/                       синхронизированные навыки для Claude Code
config/*.example.json                шаблоны интервью и источников
data/                                локальная SQLite-память
retrospectives/                      локальная история занятий
KNOWLEDGE.md                         локальная накопительная база знаний
AGENT_GUIDE.md                       общие правила наставника
AGENTS.md                            вход для Codex
CLAUDE.md                            вход для Claude Code
```

После изменения канонического навыка синхронизируйте Claude-копию и запустите проверки:

```bash
python scripts/sync_skills.py
python -m unittest discover -s tests -v
```
